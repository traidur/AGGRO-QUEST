# Brainstorm: an original "zealot monastery" faction/setting for two related games

## Context

I'm working on two related tabletop card games. **AGGRO** is the main game (long-running,
already thoroughly IP-scrubbed of any direct World of Warcraft references — if you happen to
know WoW, treat that only as background context for *why* a certain vibe is being targeted,
never as something to actually reference or name-check in your answer). **QUEST** is a
prequel/companion game sharing AGGRO's card-combat engine, structured as Zones a hero travels
through and quests inside each Zone.

Both games have a first area with a rogueish smuggler/pirate theme — stolen goods, forged
paperwork, small-scale criminal economy. Quest names in that first area are object-based:
things like "Pilfered Goods," "Forged Ledger," "Syndicate Ledger," "Contraband Crates,"
"Stolen Signet," "Smuggled Cargo," "Plundered Chest," "Buried Treasure."

For the **second area** in both games, the intended vibe is: a militant, fanatical religious
order that arose specifically to purge the corruption of the first area's criminal underworld —
but has itself curdled into something just as bad, or worse. Crimson-and-gold heraldry.
Cathedral, reliquary, and cloister imagery. Zealots who burn confessions instead of reading
them. "Relics" that are really just looted goods laundered through religious authority — same
greed as the first area, dressed up in sanctified language instead of criminal language.

## The one hard constraint

**Nothing here can be an actual name, place, or proper noun from World of Warcraft or any
other existing copyrighted property.** The *vibe* described above ("zealous purity cult,
crimson and gold, cathedral setting, hypocritical purge-the-corrupt zealotry") is fine to draw
inspiration from in a general genre sense — plenty of fantasy settings have militant religious
orders — but every actual name you propose (faction name, place name, quest names, notable
NPC/boss-type names if you want to suggest any) needs to be wholly original, not a real-world
trademark, and not a thinly-reskinned version of a specific existing property's proper noun.
If you're ever unsure whether a name is too close to something specific, err toward more
original and flag the concern rather than proposing it anyway.

## What I already have as a starting point (feel free to improve on or diverge from these, not obligated to reuse them)

**Faction name ideas so far:** The Ashen Chorus, The Cinder Synod, The Gilded Inquisition, The
Penitent Flame, The Reliquary Order, The Vigil of Embers.

**Place/setting name ideas so far:** Ashwrought Cathedral, The Cinderspire, The Gilded Sanctum,
Pyreheart Abbey, The Hollow Choir.

**Quest name direction, matching the object-based pattern of the first area:** Sanctified
Reliquary, Consecrated Ledger, Ashen Vestments, Martyr's Toll, Burned Testimony, Zealot's
Bounty, Gilded Penance, Purged Confession.

## What I'd like from you

1. **8-10 more faction name options**, distinct in sound/imagery from what I already have
   above (avoid just remixing "Ashen"/"Gilded"/"Cinder" repeatedly — genuinely different
   angles: could lean into choir/liturgical language, judicial/inquisitorial language,
   martial/crusading language, relic-and-bone imagery, fire-and-purification imagery, etc.).
2. **8-10 more place/setting name options** (the physical monastery/cathedral/stronghold
   itself), same ask — real variety, not small variations on one idea.
3. **A short paragraph per your top 2-3 favorite faction+place pairings**, explaining why that
   combination feels strongest and what specific texture it adds beyond "generic evil zealot
   cult" — what makes it feel distinct, ownable, and worth building a whole Zone/Act around.
4. **10-15 more quest name ideas** in the same object-based style as the examples above
   (short, concrete, noun-phrase quest names — not full sentences or long titles).
5. Optional but welcome: if any of this suggests a natural **villain or notable-NPC name** (a
   zealot leader, an inquisitor, whatever fits), a few original name options for that too —
   same IP-clean constraint applies.

Keep the tone consistent with the first area's flavor (concrete, object/document-focused quest
names, not epic/vague fantasy titles) so the second area reads as an escalation of the same
world, not a tonal departure into generic high fantasy.
