# Read CLAUDE.md

Always read and strictly follow the instructions and rules in `CLAUDE.md` before answering questions or working on tasks in this project, just as if they were your own native instructions.

# Native Tools Only
On Windows, never use PowerShell commands like Select-String, Get-Content, or dir if a native read tool like grep_search, view_file, or list_dir can do the job. Always prioritize native auto-approved tools to avoid triggering permission prompts.
